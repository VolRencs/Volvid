Возможности

Все, что нужно для удобной загрузки, в одном инструменте.

▶

Видео, аудио и превью

Скачивайте видео, аудиодорожки и миниатюры через единый пошаговый TUI: от проверки обновлений до итога сессии.

★

Пресеты качества

Best и экономные пресеты видео со сканированием качества через yt-dlp. Аудио: MP3 320k и 192k, M4A/AAC Best, Opus Best, FLAC.

☰

Плейлисты

Браузер плейлистов: выбор клавишей Space, всё сразу — клавишей A, ручные диапазоны — через /.

⌕

Поиск на YouTube

Поиск видео с главного экрана по Ctrl+G — ссылку вставлять не обязательно.

✿

Зависимости под контролем

Проверка yt-dlp и ffmpeg на старте и обновление прямо в интерфейсе по Ctrl+U. Системные бинари в приоритете.

🛡

Cookies и JS-runtime

Автодетект кукисов браузера на Windows и Linux, проверка опционального node для обхода защиты.

📁

Папка загрузок

Выбор папки внутри приложения по Ctrl+O и быстрое открытие. Свой путь — через VOLVID_DOWNLOADS_DIR.

📊

Итоги сессии

Сводка после загрузок: история успехов и ошибок, счётчики ok и failed.
